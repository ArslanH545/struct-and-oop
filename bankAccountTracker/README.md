# Bank Account Tracker

A simple C++ bank account system built to practice structs, pointers, constructors, references, and member functions.

## Features

- Create bank accounts with unique account numbers
- Deposit and withdraw money
- Transfer money between accounts
- Track transaction counts
- Display account information

## C++ Concepts Practiced

- Structs
- Pointer members
- Const pointers
- Constructors and initializer lists
- Instance methods
- Static methods
- Pass by reference
- Pointer dereferencing

## Compile

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic -Werror bankAccountTracker.cpp -o b

```run
./b
